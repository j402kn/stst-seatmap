        1. 予約メール本文（基本）

        ■公演名／会場／公演日時

2F BOX13 3番

Class A     2F BOX13 3番
Premium seat  【レモネード】スーパーセーラームーン  1F Dブロック 3列 5番
BOX Room  ドリンクなし  2F BOX Room9 1番

        3. JSON

        [{"date":"1970-01-01","time":"00:00","seat":"1F Aブロック1列1番","drink":"煎茶（ホット）","kind":"Premium seat","team":"Gold"}]

        4. タブ区切り（列：日付・時間・席・のみもの・席種・チーム）

        1970-01-01[Tab]00:00[Tab]1F Aブロック1列1番[Tab]煎茶（ホット）[Tab]Premium seat[Tab]Gold

        5. CSV（1行目の見出しは省略可）

        date,time,seat,drink,kind,team
1970-01-01,00:00,1F Aブロック1列1番,煎茶（ホット）,Premium seat,Gold
